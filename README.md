## Install on Windows

1. Open the latest release on the Releases page of this repository.
2. Download install.cmd and double-click it. Windows may warn that the file comes from the internet; choose More info, then Run anyway.
3. Wrought installs for your Windows user only (no admin rights needed), adds itself to the Start menu and opens.

Wrought then keeps itself up to date: once a day, and when you sign in, it checks this repository for a newer release, checks every download against the release's SHA256SUMS file and installs it once Wrought is closed. The version before is kept, so it can be put back.

To remove Wrought, use Settings, Apps, Installed apps, Wrought, Uninstall. Your settings are kept in %APPDATA%\Wrought.

## Install on Linux

Download the .deb file from the latest release and run setup.sh next to it, or open the .deb with your software installer.
